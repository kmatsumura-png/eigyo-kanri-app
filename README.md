# 営業管理ダッシュボード

トップチーム5人（松村・榎本・森・辻本・早坂）の 2026年7〜9月 の営業実績を、
**「開いて30秒で、誰が好調か・誰が落ちているか・誰に何を指導するか」** が分かるように見せるアプリです。

> 作った時の整理（どの数字をどのファイルから取ったか・計算方法など）は [docs/設計メモ.md](docs/設計メモ.md) にあります。

---

## はじめて使うとき（最初の1回だけ）

### 1. Node.js（ノード）を入れる
アプリを動かすための土台です。https://nodejs.org/ja から **LTS（推奨版）** をダウンロードしてインストールしてください。

### 2. このアプリをパソコンに置く
GitHub の緑色の「Code」ボタン →「Download ZIP」でダウンロードし、好きな場所に展開します。

### 3. 黒い画面（ターミナル）を開く
- Windows：展開したフォルダを開き、上のアドレス欄に `cmd` と入力して Enter
- Mac：「ターミナル」アプリを開き、`cd ` と入力してからフォルダをドラッグ＆ドロップして Enter

### 4. 部品をインストールする
```
npm install
```
（数分かかります。最初の1回だけでOK）

---

## データを入れる・更新する

1. `excel` フォルダに次の Excel を入れます（同じ種類の古いファイルは消してください）
   - 営業管理システム (1).xlsx
   - トップチーム行動予定表.xlsx
   - _トップチーム 評価基準用数値集計 2026年7月.xlsx（8月・9月も）
   - 営業管理_7-9月_5人_KPI確定版.xlsx（あれば。行動数・GET数・ポイントはこれを最優先で使います）
2. 黒い画面で次を実行します
   ```
   npm run import
   ```
3. 「✅ 取り込み完了」と出れば成功です。

> ⚠ Excel と取り込んだデータには顧客名・住所が入っているため、**GitHub には上がらない設定**にしてあります。

---

## アプリを起動する

```
npm run dev
```
を実行し、ブラウザで **http://localhost:3000** を開きます。
終わるときは黒い画面で `Ctrl` + `C` を押します。

スマートフォンで見たい場合は、同じWi-Fiにつないだ状態で `http://（パソコンのIPアドレス）:3000` を開きます。

## 画面の使い方

| 画面 | 何が分かるか |
|---|---|
| ダッシュボード | チーム全体の数字・30秒でわかる要点・ランキング・グラフ |
| メンバー | 5人の 7月／8月／9月／3か月平均 の比較 |
| 個人ページ（名前をクリック） | その人の数字・**課題と改善の目安**・商談一覧・契約案件 |
| 案件一覧 | 契約案件と商談の一覧、商品別の件数、金額の修正 |
| 分析 | 誰の「アポ→行動→成約→単価」のどこに課題があるか |
| データ確認 | 数字の出どころ、ファイル同士の食い違い、計算ルール |

画面上の「7月／8月／9月／7〜9月」で期間、「全員／松村…」で見る人を切り替えます。

---

## 契約金額を修正する

1. 「案件一覧」→「金額要確認」タブを開く
2. 直したい案件の「確認・修正」を押す
3. 元の備考を見ながら、**契約金額（最終販売価格）** を入力
   （候補の金額があれば「候補 ○○円 を入れる」ボタンで入力できます）
4. 必要なら商品名・管理者メモ・「データ確認済み」も入れて「保存する」

修正内容は `data/edits.json` に保存され、Excel を取り込み直しても消えません。

---

## 毎月やること

1. 最新の Excel を `excel` フォルダに入れ替える
2. `npm run import` を実行
3. 「データ確認」画面で **データ不一致・要確認** を確認
4. 「案件一覧」の **金額要確認** を確認・修正
5. ダッシュボード → 気になる人 → 課題 → 商談・契約 の順に見て指導に使う

### 対象の月や人を変えたいとき
`lib/config.ts` の `MONTHS`（対象月）・`MEMBERS`（対象メンバー）・`PERIOD_TITLE`（タイトル）を書き換えます。
新しい月の「評価基準用数値集計」ファイルも `excel` フォルダに入れてください。
（期間切り替えボタンの「7〜9月」の文字は `components/Header.tsx` にあります）

## 機能を追加したいとき

| やりたいこと | 触るファイル |
|---|---|
| 自動コメント・課題判定のルールを変える | `lib/insights.ts` |
| 判定の厳しさ（85%）を変える | `lib/insights.ts` の `ISSUE_LINE` |
| 商品の分類を変える | `lib/config.ts` の `PRODUCT_CATEGORIES` |
| 金額の読み取りルールを変える | `lib/parse.ts` |
| KPIの計算方法を変える | `lib/kpi.ts` |
| 画面の見た目を変える | `app/` の各 `page.tsx`、`components/` |
| AIコメントを追加する | `lib/insights.ts` の関数を、AIを呼ぶ処理に差し替える（画面はそのまま使えます） |

Claude Code などに「`lib/insights.ts` に○○のルールを追加して」と頼むのが簡単です。

## 使っている技術（参考）

- Next.js（画面を作る仕組み）／TypeScript（間違いに気づきやすいプログラム言語）
- Tailwind CSS（見た目の設定）／Recharts（グラフ）／SheetJS（Excel 読み込み）
- データは JSON ファイル（`data/` フォルダ）に保存
